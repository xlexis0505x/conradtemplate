# teenage.engineering — Local Source Code & Assets

Cloned from: https://teenage.engineering/

## 📁 Directory Structure
- `index.html`: Clean, formatted DOM featuring Swiss/Nordic brutalist typography, responsive layout, and product grids.
- `assets/`: 
  - Custom Teenage Engineering fonts: `TE20L.B96qqQct.woff2`, `TE20T.woff2`, `TE40L.woff2`
  - Modular component styles & scripts: `button.*.js`, `button.*.css`, `container.*.js`, `flex.*.js`, `entry.client.*.js`
- `_external/`: High-resolution product renders and WebP imagery.
- `server.py`: Standalone local development server.

## 🚀 Running Locally
```bash
python3 server.py
# Serves at http://localhost:8084/
```
Or with custom port:
```bash
python3 server.py 9000
```
