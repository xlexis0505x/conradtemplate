# helionenergy.com — Local Source Code & Assets

Cloned from: https://www.helionenergy.com/

## 📁 Directory Structure
- `index.html`: Clean, formatted DOM with fusion physics storytelling, plasma animations, and energy metrics.
- `src/`: **Reconstructed original uncompiled JavaScript source code** recovered from Source Maps:
  - `src/gh/nocodesupplyco/mast@HEAD/theme-toggle.js`
- `_external/`: Stylesheets, vector assets, and video loops.
- `server.py`: Standalone local development server.

## 🚀 Running Locally
```bash
python3 server.py
# Serves at http://localhost:8083/
```
Or with custom port:
```bash
python3 server.py 9000
```
